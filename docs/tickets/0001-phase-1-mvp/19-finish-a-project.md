# 19: Finish a project

**What to build:** A project that reached its goal can be closed properly — a distinct, deliberate act that preserves the final numbers and stops the project competing for daily attention.

**Blocked by:** 18

**Visuals:** every screen this ticket touches must match [`docs/interface-preview.html`](../../interface-preview.html) — see [spec 0002](../../specs/0002-web-interface-design.md). Structure, copy, tokens and components are normative; "works but looks different" is not done.

**Status:** done

- [ ] Finishing requires an explicit second confirmation; cancelling leaves the project exactly as it was.
- [ ] A finished project leaves the active list, appears under Completed, and stops being an alert candidate.
- [ ] The final streak and the all-time longest streak are preserved and displayed on the finished project.
- [ ] Finishing is irreversible through the interface — there is no un-finish control.
- [ ] A finished project is excluded from today's cards and from completion-rate denominators.
